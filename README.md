# CSCU9X5 HCI-UX Assignment 1 — proof of process

Student number 30068298.

This repository holds the working material for the NetStart
"learn computer networking from zero" web prototype and its design report. It
is the version-controlled evidence of process referred to on the assessment
coversheet.

## What is here

| Path | What it is |
| --- | --- |
| `site/` | The finished web application. Open `site/HomePage.html` in a browser; no server or install needed. |
| `drafts/` | Intermediate drafts of the report and the photo from the usability session. |
| `wireframes/` | The three hand-drawn wireframes used before any HTML was written. |
| `QA-notes.md` | Running notes taken while reviewing the site: what broke, what was changed. |
| `README.md` | The original working notes for the build. |

## The site

Five pages, all static HTML/CSS/JavaScript with Bootstrap vendored locally so
the site runs offline:

- `HomePage.html` — landing page, progress overview, mascot
- `basics.html` — the first two weeks of networking content
- `concepts.html` — searchable reference of core terms
- `quiz.html` — the practice quiz with scoring
- `cheatsheet.html` — print-friendly one-page summary

## Notes on AI use

AI assistance was used at the level allowed for this assessment and is declared
on the coversheet. The report prose, the design decisions and the usability
findings were reviewed and rewritten by the student before submission.
