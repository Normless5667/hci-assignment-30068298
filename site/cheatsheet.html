Diagnostic commands

CommandAnswers
ipconfig /allWhat address, mask, gateway and DNS do I have?
ping hostCan I reach it, and how long does a round trip take?
tracert hostWhich routers does the path go through?
nslookup nameWhat address does DNS return?
netstat -anoWhich ports are open, and by which process?

HTTP status codes

CodeMeaning
200OK
301 / 302moved — follow the new location
404the server has no such resource
500the server failed handling the request

The first digit is the family: 2xx success, 3xx redirect, 4xx your request, 5xx their fault.

Exam habit. When a question describes a fault, name the layer before you name the fix. "Ping works, browsing fails" is not a cable problem; it is DNS or a port.
